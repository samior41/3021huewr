# 🖤💛 mastalk

Mastodon에서 나눈 대화를 백업하여 개인 홈페이지 형태로 열람할 수 있도록 만든 소스를 공개 배포합니다.

별도의 호스팅이나 데이터 저장소는 필요하지 않습니다.

웹브라우저의 캐시와 기기의 로컬 저장소를 이용하기 때문에, 사용하는 기기나 브라우저에 따라 별도의 설정이 필요할 수 있습니다.

GitHub Pages, 나루 등 HTML/CSS 파일을 업로드할 수 있는 무료 정적 웹페이지 서비스에 적합하며, 별도의 웹 호스팅을 구매하지 않고도 편리하게 백업 페이지를 구축할 수 있습니다.

반드시 웹사이트에 업로드해야 하는 것은 아니며, 파일을 데스크톱에 저장한 뒤 로컬 페이지로 실행하여 열람하는 것도 가능합니다.

> ⚠️ 본 백업소스는 Chrome 확장 프로그램 「Mastodon Scraper」에서 HTML 형식으로 백업한 파일에 최적화되어 있습니다.

## 사용방법

#### 1. Mastodon 대화 백업하기

먼저 Chrome 확장 프로그램 Mastodon Scraper를 이용하여 대화를 [HTML] 형식으로 백업합니다.

백업한 .html 파일은 소스 폴더 안의 `toots` 폴더에 넣어주세요. 파일명은 자유롭게 설정 가능합니다.

#### 2. 캐릭터 정보 수정하기

`apply_theme.js` 파일을 메모장, VS Code 등의 편집기로 실행합니다.

파일의 19번째 줄 부근에서 아래 `CHARACTERS` 를 찾아 캐릭터 정보에 맞게 label과 account를 수정합니다.

```js
// 캐릭터 등록 시, 아래의 label과 account를 수정해주세요.
// 색상 코드는 홈페이지 내부에서 직접 수정이 가능하니 반드시 여기서 설정할 필요는 없습니다.
// 아래 CHARACTERS를 하나라도 수정했을 경우에는, node apply_theme.js 를 실행합니다.
const CHARACTERS = {
  char1: { label: "캐릭터1", account: "@계정", side: "left", colorLight: "#2f6690", colorDark: "#7fbbe8" },
  char2: { label: "캐릭터2", account: "@계정", side: "right", colorLight: "#8c4a63", colorDark: "#dd93ab" },
};
```

각 항목의 의미는 다음과 같습니다.

- label : 홈페이지에 표시할 캐릭터 이름
- account : Mastodon 계정명
- side : 대화창에서 표시될 방향
- colorLight : 라이트 모드 말풍선 색상
- colorDark : 다크 모드 말풍선 색상

색상은 홈페이지 생성 후 직접 변경이 가능하며, 위는 기본값 세팅입니다.

#### 3. 테마 적용하기

이제 Powershell 또는 Terminal을 실행한 뒤, mastalk 폴더로 이동하여 아래 명령어를 실행합니다.

```
node apply_theme.js
```

> ⚠️ 주의: 실행 과정에서 폴더 경로에 한글이 포함되어 있을 경우 오류가 발생할 수 있습니다.
> 가능하면 mastalk 폴더를 포함한 전체 경로와 폴더명을 영어로 통일해주세요.

#### 4. 생성된 파일 확인하기

명령어가 정상적으로 실행되었다면 mastalk 폴더 안에 다음 파일들이 생성됩니다.

- index.html
- manifest.js
- style/ttobot.css

세 파일이 정상적으로 생성되었다면 홈페이지 제작이 완료된 것입니다.
